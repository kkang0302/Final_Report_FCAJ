### Week 7 Objectives:

* Conduct comprehensive End-to-End (E2E) integration testing of the entire system.
* Verify access control scenarios (Role-Based Access Control) using the Custom Lambda Authorizer.
* Optimize PostgreSQL database performance on Amazon RDS.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 1 | - Set up E2E testing scenarios: Register/Login -> Browse Courses -> Purchase via Stripe -> Enroll -> Progress Tracking | 27/07/2026 | 27/07/2026 | E2E Testing Scenarios |

### Week 7 Achievements:

* Successfully tested the complete E2E user workflow, from registering an account to course registration and progress tracking.
* The Lambda Authorizer and RBAC (Role-Based Access Control) worked correctly, keeping APIs secure.
* DB queries response times improved substantially, and query overhead was resolved by creating targeted indexes and fixing $N+1$ queries.
* Connection pooling acts efficiently, protecting the database from concurrent connection exhaustion during traffic peaks.
* **ECS Fargate & Cloud Map Verification**: Confirmed microservice containers are successfully pushed to Amazon ECR and run stably on Amazon ECS; validated internal dynamic DNS routing via Cloud Map (Service Discovery) for secure inter-service connection inside the VPC.
